# 言录

言录（`yanxu-log`）1.0.0 是面向言序 1.1.6+ 的结构化日志库。它提供六级日志、稳定记录模式、JSON Lines、言据、控制台与轮转文件处理器，并把上下文、脱敏、采样和请求/数据库集成放在同一条受资源预算保护的管线中。

## 安装

```sh
yanbao add log --package 言录 --version "^1.0"
```

等价清单：

```toml
[依赖]
言录 = { git = "https://github.com/yanxulang/yanxu-log.git", 修订 = "v1.0.0", 版 = "^1.0" }
```

言录锁定已发布的言据 1.2 稳定线，用于规范言据记录格式。

## 快速开始

```yanxu
引「包:言录」为 言录；

定 文件器 为 言录.JSON文件处理器（「应用.jsonl」，言录.信息级，10485760，5）；

定 日志 为 言录.日志器（
    言录.追踪级，
    「订单服务」，
    「HTTP」，
    【言录.控制台处理器（言录.调试级），文件器】，
    {「环境」：「生产」}
）；

日志.子日志器（「创建订单」，{「请求号」：「r-42」}）
    .信息于（「创建成功」，{「订单号」：「o-1」，「Authorization」：「不会泄漏」}）；
```

每条记录都有`模式版本`、时间戳、等级、消息、模块、频道和结构化字段。上下文与输入会深拷贝；处理器和采样器获得隔离副本。默认敏感键按大小写不敏感匹配并递归替换。

## 能力

- 追踪、调试、信息、警告、错误、致命六级日志；
- 子日志器、频道与继承式结构化上下文；
- JSON Lines、言据和可读控制台格式；
- 控制台、内存、函数和轮转文件处理器；
- 固定间隔与自定义采样器，可始终保留高等级记录；
- 容错处理器，用于隔离可选输出端故障；
- 稳定`YANLU_`错误详情与明确资源上限；
- 请求和数据库标准字段构造器及日志器便捷入口；
- 可注入时间源，便于测试和回放。

## 请求和数据库

```yanxu
日志.记请求（
    「请求完成」，「POST」，「/orders?token=secret」，201，18，
    {「Authorization」：「Bearer secret」}，
    {「请求号」：「req-1」}
）；

日志.记数据库（
    「查询完成」，「PostgreSQL」，「查询」，
    「SELECT id FROM orders WHERE id = $1」，7，1，
    {「id」：42}，{「事务号」：「tx-1」}
）；
```

请求目标会移除查询和片段；绝对 HTTP 地址还会移除整个权限部分。认证首部、Cookie、令牌、连接串和数据库参数中的常见敏感键在字段构造阶段即被替换。SQL 参数应与语句模板分离，禁止把凭据拼入模板文字。

## 权限

内存与控制台 API 不访问网络、环境、进程或原生扩展。文件处理器受言序文件权限控制；顶层应用须只授权实际日志目录。言录不创建目录，也不管理多进程文件锁。
