# 言录记录模式 v1

每条由`日志器`创建的记录都是典，`模式版本`固定为`1`：

```text
{
  模式版本: 1,
  时间戳: 非负整数毫秒,
  等级: 追踪|调试|信息|警告|错误|致命,
  等级值: 整数,
  消息: 文字,
  模块: 文字,
  频道: 文字,
  字段: 典,
  错误?: 典
}
```

## 基础字段

| 字段 | 类型 | 语义 |
| --- | --- | --- |
| `模式版本` | 数 | 当前为 1；消费者应拒绝未知主模式。 |
| `时间戳` | 数 | Unix 毫秒；可由应用注入时间源。 |
| `等级` | 文 | 根据`等级值`映射的中文名称。 |
| `等级值` | 数 | 整数；预定义范围为 10 至 60。 |
| `消息` | 文 | 人类可读摘要，不应用于机器分支。 |
| `模块` | 文 | 点号分隔的子日志器模块。 |
| `频道` | 文 | 独立分类维度。 |
| `字段` | 典 | 复制、合并并脱敏后的结构化上下文。 |
| `错误` | 典 | 仅`记错误`或带`误`的`写`存在。 |

`错误`包含`代码`、`类别`、`消息`、`位置`和`踪迹`。错误自由文本不会按内容脱敏。

## HTTP 请求事件

`请求字段`产生：

```text
{
  事件类型: HTTP请求,
  请求: {
    方法: 文,
    目标: 不含查询和片段的路径,
    状态码: 数|空,
    耗时毫秒: 数,
    首部: 典
  },
  ...扩展
}
```

标准字段覆盖同名扩展，扩展不能伪造`事件类型`或`请求`。绝对 HTTP 地址移除权限部分，避免用户信息进入日志。

## 数据库事件

`数据库字段`产生：

```text
{
  事件类型: 数据库,
  数据库: {
    系统: 文,
    操作: 文,
    语句模板: 文,
    耗时毫秒: 数,
    影响行数: 数|空,
    参数: 典
  },
  ...扩展
}
```

标准字段同样覆盖扩展。参数按默认敏感键递归脱敏；语句模板必须由调用方保证不含文字常量凭据。

## 编码

- `JSON行格式`生成一个紧凑 JSON 对象，不附加换行；文件处理器统一追加一个 LF。
- `言据格式`生成一个言据`据`值，不附加换行。
- `控制台格式`面向人类，不作为稳定机器协议。

记录只允许空、逻辑、数、文、列和文字键典。JSON 不能表示的数或对象在进入处理器前被拒绝。

## 演进规则

1. 1.x 可增加可选字段，但不删除或改变以上字段类型。
2. 新的请求/数据库子字段应保持旧消费者可以忽略。
3. 不兼容变更必须提高`模式版本`并在迁移文档说明。
4. 消费者应按字段名解析，不依赖典的显示顺序。
