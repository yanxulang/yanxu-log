# 言录使用指南

## 创建日志器

`日志器(最低等级, 模块, 频道, 处理器列, 上下文)`是完整入口。低于日志器最低等级的调用立即返回`空`，不会创建记录、推进采样器或调用处理器。

```yanxu
定 内存 为 言录.内存处理器（言录.追踪级，言录.JSON行格式）；

定 日志 为 言录.日志器（
    言录.信息级，
    「账户服务」，
    「业务」，
    【言录.控制台处理器（言录.警告级），内存】，
    {「环境」：「生产」}
）；
```

`新建(最低等级)`创建控制台日志器；`静默(最低等级)`创建没有处理器的日志器，适合逐步组装或测试。

## 等级和结构化字段

六个预定义等级值依次为 10、20、30、40、50、60。每一级都有纯消息方法和带字段方法：

```yanxu
日志.信息（「服务已启动」）；
日志.警告于（「库存不足」，{「商品号」：「p-1」，「剩余」：2}）；
```

`写(等级, 消息, 字段, 所误)`支持自定义整数等级。`记错误`会把言序`误`的代码、类别、消息、位置和踪迹加入`错误`字段。

## 子日志器和上下文

`子日志器`用点号连接模块名，并把新上下文覆盖到父上下文；`频道`只替换频道；`上下文`只增加字段。

```yanxu
定 请求日志 为 日志
    .子日志器（「创建账户」，{「请求号」：「r-42」}）
    .上下文（{「追踪号」：「trace-7」}）；
```

父子日志器共享处理器和已显式启用的采样器，但上下文、敏感键和记录值会复制。创建后修改原始典或列，不会回写日志器。

## 脱敏

默认敏感键覆盖常见中文与英文凭据名，包括密码、令牌、认证首部、Cookie、客户端密钥、API Key、DSN 和数据库连接串。匹配忽略大小写并递归进入列和典。

```yanxu
日志.设脱敏（【「密码」，「访问令牌」，「Authorization」】，「[已隐藏]」）；
```

`默认敏感键()`返回新列表；`脱敏(字段, 敏感键, 替代)`可独立使用。脱敏只按键名处理结构化值，不扫描自由文本。消息、错误消息和 SQL 模板不得包含凭据。

## 采样

默认日志器不采样。固定间隔采样器保留每个周期的第一条低等级记录，并始终保留达到保护等级的记录：

```yanxu
日志.固定采样（10，言录.警告级）；
```

也可显式持有采样器查看计数或重置：

```yanxu
定 采样器 为 言录.固定间隔采样器（10，言录.错误级）；
日志.设采样器（采样器）；
```

自定义对象只需提供`保留(记录:典):理`。跨模块协议采用结构化调用边界；采样器收到隔离副本，修改它不会改变最终记录。异常会转换为`YANLU_SAMPLER`。被采样丢弃的调用返回`空`。

## 处理器

### 控制台和函数

`控制台处理器`使用可读格式并输出一行。`函数处理器`接收最低等级、格式化法和写出法：

```yanxu
法 格式（记录：典）：文 则
    归 （记录【「等级」】 加 「：」 加 记录【「消息」】）；
终

法 写出（正文：文，记录：典）：空 则
    言 正文；
    归 空；
终

日志.加处理器（言录.函数处理器（言录.信息级，格式，写出））；
```

每个处理器获得自己的记录副本。默认情况下处理器错误向调用者传播。可选的`容错处理器(内层)`捕获错误，并通过`失败数()`和`最近错误()`报告；它适合遥测等非关键输出，不应掩盖主审计日志故障。

### 内存

`内存处理器`保存格式化文本和结构化记录，最多 4096 条。`各文本()`与`各记录()`返回副本；`记录数()`是常数时间；`清空()`释放已存内容。

### 文件与轮转

```yanxu
定 文件器 为 言录.JSON文件处理器（
    「logs/app.jsonl」，言录.信息级，10485760，5
）；
```

轮转阈值按 UTF-8 字节计算。下一条记录会越过阈值时，当前文件复制到`.1`，旧备份依次移到`.2`至`.N`。单条记录不拆分，因此可大于较小的轮转阈值，但仍不能超过 1 MiB 单条预算。`轮转字节=0`关闭轮转；`保留份数=0`轮转时只清空当前文件。

文件处理器不创建父目录，不提供跨进程锁，也不承诺原子重命名。一个路径只应由一个进程写入。

## 请求日志

`请求字段`可供请求库直接构造字段，`记请求`是信息级便捷入口。绝对 HTTP 地址只保留路径；相对目标移除查询和片段。认证首部与扩展中的常见敏感键立即脱敏。

```yanxu
日志.记请求（
    「请求完成」，「GET」，「/users?token=secret」，200，12，
    {「Authorization」：「Bearer secret」}，
    {「请求号」：「r-1」}
）；
```

调用方应记录路由模板或路径，不记录原始正文。请求耗时须为非负整数毫秒，状态码为`空`或 100 至 599 的整数。

## 数据库日志

`数据库字段`和`记数据库`分离语句模板与参数：

```yanxu
日志.记数据库（
    「查询完成」，「PostgreSQL」，「查询」，
    「SELECT id FROM users WHERE id = $1」，8，1，
    {「id」：42}，
    {「事务号」：「tx-1」}
）；
```

参数和扩展按默认敏感键脱敏。语句模板是自由文本，不会内容扫描；只应传参数化模板，不得传拼接后的完整 SQL。

## 可确定时间

测试或回放可注入无参数、返回非负整数毫秒的时间源：

```yanxu
法 固定时间（）：数 则
    归 1700000000000；
终

日志.设时间源（固定时间）；
```

子日志器继承时间源。

## 错误处理

库错误消息以`YANLU_<代码>：`开头。`错误详情(所误)`恢复稳定代码，并保留源错误信息。常见代码包括`LIMIT`、`LIMIT_CONFIG`、`FIELD_KEY`、`FIELD_VALUE`、`REDACTION`、`ROTATION`、`PATH`、`SAMPLER`和`INTEGRATION`。
