# 从 0.1 迁移到 1.0

## 依赖

把依赖范围和修订从开发分支改为稳定标签：

```toml
[依赖]
言录 = { git = "https://github.com/yanxulang/yanxu-log.git", 修订 = "v1.0.0", 版 = "^1.0" }
```

言录内部的言据依赖已固定为`v1.2.0 + ^1.2`。最低言序仍为 1.1.6。

## 兼容保留

以下 0.1 API 保留：

- 六个等级常量与`等级名`；
- `日志器`构造器和六级消息/字段方法；
- `子日志器`、`频道`、`上下文`；
- 控制台、内存、函数、JSON 文件、言据文件处理器；
- `JSON行格式`、`言据格式`、`控制台格式`；
- `新建`和`静默`。

## 行为变化

### 记录模式

记录新增`模式版本: 1`。解析固定字段的消费者应允许该字段；依赖完整典相等的测试需要更新期望值。

### 输入复制

上下文、字段、处理器副本和内存快照现在深拷贝。依赖“写入后修改原始典会改变历史记录”的代码属于未定义共享行为，应移除。

### 脱敏

敏感键匹配改为忽略大小写，默认集合增加认证首部、Cookie、客户端密钥、API Key、DSN 和连接串。确实需要记录同名非敏感业务字段时，应显式调用`设脱敏`使用更窄集合，并确认安全影响。

### 资源错误

过深、过宽、不可编码或超大值不再等待运行时栈溢出、内存耗尽或格式化器偶然失败，而是抛出稳定`YANLU_`错误。可用`错误详情`读取代码。

### 文件轮转

轮转阈值从文字字符数修正为真实 UTF-8 字节数。含中文的记录可能比 0.1 更早轮转。轮转阈值必须是 0 至 64 MiB 的整数，保留份数最多 128。

单条记录仍不拆分，可大于很小的轮转阈值，但不得超过 1 MiB 单条预算。

### 处理器

每个处理器获得独立记录；一个自定义处理器的修改不再影响后续处理器。处理器错误仍默认传播。若某输出端允许降级，显式包裹`容错处理器`并监控失败计数。

## 新能力

- `设时间源`支持确定性测试；
- `固定间隔采样器`、`固定采样`和结构化自定义采样器；
- `记录数`避免复制完整内存快照；
- `请求字段`、`记请求`；
- `数据库字段`、`记数据库`；
- `默认敏感键`与稳定记录模式文档。

## 安全迁移检查

1. 搜索消息和 SQL 模板中拼接的凭据；键名脱敏不会扫描自由文本。
2. 确认文件目录已存在且权限最小化。
3. 确认一个日志路径只有一个写入进程。
4. 用请求字段构造器代替直接记录完整 URL 和认证首部。
5. 用数据库字段构造器分离语句模板和参数。
