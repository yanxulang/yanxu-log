# 言录 1.0.0

言录 1.0.0 把首版日志能力推进为有稳定模式、安全预算、采样与集成契约的基础库，同时保留 0.1 的主要入口。

## 主要内容

- 结构化记录增加`模式版本: 1`，提供独立模式文档。
- 六级日志、子日志器、频道、上下文和错误记录入口保持兼容。
- JSON Lines、言据、控制台、内存、函数和轮转文件处理器形成统一管线。
- 深层值先做非递归预算预检，再深拷贝和递归脱敏。
- 敏感键改为大小写不敏感，覆盖常见认证、Cookie、API Key 和数据库连接凭据。
- 固定间隔采样支持始终保留高等级记录；外部采样器采用结构化调用边界。
- 容错处理器提供显式、可观察的输出端降级。
- 时间源可注入，子日志器继承，测试和示例可确定。
- 文件轮转按真实 UTF-8 字节计算，配置和单条记录受硬预算保护。
- 请求构造器移除查询、片段和绝对地址权限部分，并脱敏首部。
- 数据库构造器分离语句模板与参数并脱敏参数。

## 依赖

- 最低言序：1.1.6。
- 言据：`v1.2.0`，语义范围`^1.2`。
- 网络、TCP、UDP、环境、进程、原生扩展：不申请。
- 文件：仅文件处理器需要，由言序权限模型和顶层应用约束。

## 验证

- 5 卷规格覆盖等级、上下文、格式、轮转、资源、隔离、采样、容错、请求和数据库集成。
- 4 个示例覆盖服务文件日志、自定义处理器、采样、请求和数据库。
- 128 条嵌套结构化日志性能回归在默认执行预算内完成。
- 规格、示例和基准同时执行树解释器与字节码 VM 对照。
- CI 在 Linux、macOS、Windows 使用最低言序 1.1.6，并用当前稳定言序执行完整质量门禁。

## 兼容提示

- 记录新增`模式版本`。
- 轮转按 UTF-8 字节而不是字符计算。
- 输入和快照不再共享可变嵌套值。
- 超限或不可编码值现在返回稳定错误。
- 默认敏感键范围扩大。

完整替换方式见`docs/MIGRATION_1.0.md`。
